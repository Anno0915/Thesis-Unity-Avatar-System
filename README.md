#　生成ＡＩ駆動型ＡＲ対話システム

##　概要

本リポジトリは、高専卒業研究「環境情報と身体的インタラクションを統合した生成ＡＩ駆動型ＡＲ対話システムの開発」で作成したＵｎｉｔｙプロジェクトである。

本研究では、従来のテキスト中心の対話型ＡＩでは表現しにくい、自然で身体性のあるインタラクション体験の実現を目的とした。具体的には、ユーザーの音声入力、アバターへの身体接触、天気や時刻などの環境情報を統合し、生成ＡＩの応答をアバターの発話、表情、視線追従、リップシンク、空間内のオブジェクト生成として表現するシステムを開発した。

##　主な機能

-　テキスト入力および音声入力による対話
-　Ｇｏｏｇｌｅ　Ｇｅｍｉｎｉ　ＡＰＩを用いた応答生成
-　会話履歴を考慮した文脈管理
-　天気・時刻などの環境情報をプロンプトに反映
-　Ｒａｙｃａｓｔを用いたアバターへの身体接触検知
-　感情タグに基づくアバター表情制御
-　Ｌｏｏｋ－Ａｔ　ＩＫによる視線追従
-　ＶＯＩＣＥＶＯＸを用いた音声合成
-　音声波形に基づく簡易リップシンク
-　会話内容に応じた３Ｄオブジェクト生成

##　システム構成

本システムは、以下の３層構造で設計した。

###　１．知覚層

ユーザーや外部環境からの入力を取得する層である。テキスト入力、音声入力、身体接触、天気、時刻などを取得し、生成ＡＩが扱いやすい形式へ変換する。

###　２．思考層

取得した入力情報をもとに、Ｇｅｍｉｎｉ　ＡＰＩへリクエストを送信し、アバターの応答内容や感情表現を決定する層である。会話履歴や環境情報を組み込むことで、文脈に応じた応答生成を目指した。

###　３．表現層

生成ＡＩの応答を、アバターの発話、表情、視線、リップシンク、オブジェクト生成として出力する層である。単なるテキスト応答ではなく、身体性と空間作用を伴う対話体験を実現することを目的とした。

##　実装上の特徴

###　マルチモーダル入力の統合

音声、身体接触、環境情報を統合し、ユーザーの発話内容だけでなく、周囲の状況や身体的な関わりも対話に反映できるようにした。

###　構造化データによる応答制御

生成ＡＩの応答を通常の文章だけで扱うのではなく、発話内容、感情、生成対象などの情報として解釈し、アバター制御やオブジェクト生成に利用した。

###　アバター表現との連携

感情タグをアニメーションパラメータに対応付け、表情変化や視線追従を行うことで、応答内容と身体的表現が連動するように設計した。

##　動作検証

本研究では、主に以下の観点から動作検証を行った。

-　音声入力による対話が成立するか
-　天気や時刻などの環境情報が応答に反映されるか
-　身体接触に対してアバターが適切に反応するか
-　生成ＡＩの応答が表情や空間作用に反映されるか
-　応答レイテンシが対話体験として許容できる範囲にあるか
-　音声と口の動きに一定の対応関係があるか

検証の結果、平均約２．７秒の応答レイテンシで対話が可能であり、音声入力、環境情報、身体接触、アバター表現を統合した対話システムとして基本的な動作を確認した。
